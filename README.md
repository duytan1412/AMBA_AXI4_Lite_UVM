## What Is Implemented

- UVM-style agent architecture: driver, monitor, sequencer, scoreboard, transaction, environment, and test library.
- AXI4-Lite protocol checks for valid/ready channel stability in the interface.
- Functional coverage model source for address, strobe, operation, and response observations.
- Directed and constrained-random test intent for base, error-response, and back-to-back traffic scenarios.
- Open-source simple RTL simulation path for CI smoke checks when a full commercial UVM simulator is unavailable.

## Evidence Policy

This repo separates implemented source from tool-generated closure evidence:

- Assertions: 5 concurrent SVA properties are present in `axi4_lite_if.sv`; do not claim a larger assertion count without adding source evidence.
- Coverage: coverage model source exists, but archived coverage percentages are treated as summary evidence unless regenerated by VCS/Xcelium/Questa.
- CI: GitHub Actions is a smoke/lint path only; full UVM regression requires a simulator with UVM support.

## Run Commands

### Open-source smoke simulation

```bash
make clean
make lint
make sim
```

### Commercial UVM regression

Use a simulator with UVM 1.2 support and the included file list:

```bash
# VCS example
vcs -full64 -sverilog -ntb_opts uvm-1.2 -f filelist.f -l sim_results/base_test.log +UVM_TESTNAME=base_test
./simv +UVM_TESTNAME=base_test

# Xcelium example
xrun -sv -uvm -f filelist.f +UVM_TESTNAME=axi_error_test -l sim_results/axi_error_test.log
```

For a command template covering all planned UVM tests, see [`scripts/run_regression.ps1`](./scripts/run_regression.ps1).
